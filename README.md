# WortSchatz Pro

Тренажёр немецких слов: словарь, расписание повторений и задания к нему.
Работает офлайн, ставится на телефон как приложение, не стоит ничего.

Приложение живёт здесь: **https://igor-bond.github.io/wordschatz/**

---

## Что оно делает

Слово попадает в словарь одним из четырёх способов: вводом, темой
целиком, разбором вставленного текста или снимка страницы. Карточку —
перевод, формы, пример, транскрипцию — собирает Gemini, а формы потом
можно сверить с немецким Wiktionary бесплатно и без ключа.

Дальше слово ведёт расписание. Интервальное повторение с фазами
заучивания решает, когда его показать, а по мере освоения меняется и
вид задания: сперва узнать среди готовых вариантов, потом выбрать
потруднее, в конце написать самому. Дневная норма — 5, 10, 15 или 20
новых слов; если повторения перестают помещаться в урок три дня подряд,
норма опускается сама и говорит об этом.

Кроме плана есть Комната — двенадцать тренажёров по одному виду задания
и интерактивный рассказ от ИИ, — чат с репетитором по-немецки, лиги,
серии дней и статистика.

Разбор самого приложения встроен: **Профиль → «Как пользоваться»**.

## Как это устроено

Чистая статика: ни сборки, ни серверного кода, ни Node. Модули ES
подключаются браузером напрямую, данные лежат в IndexedDB, а
синхронизация идёт из браузера прямо в Firebase.

```
index.html          оболочка и разметка первого экрана
manifest.json       PWA: полноэкранный режим, иконки
sw.js               офлайн-кэш, стратегии и APP_VERSION

js/main.js          точка входа
js/app.js           маршрутизация между экранами
js/config.js        настройки в localStorage
js/version.js       версия, показанная в «Информации»
js/core/            чистая логика: srs, mastery, scheduler, german, declension…
js/services/        база, ИИ, Wiktionary, вход, синхронизация, миграции
js/modules/         экраны: dashboard, training, exercises, room, chat, profile, guide…
js/i18n/            строки интерфейса (ru.js) и текст справки (guide.js)

css/style.css       правила, которых нет в Tailwind
css/tailwind.css    собранные утилиты (генерируется, править не нужно)

tests/index.html    страница проверок
tests/suites/       наборы проверок

tools/serve.ps1     локальный сервер
tools/test.ps1      сервер плюс страница проверок
tools/build-css.ps1 пересборка стилей автономным Tailwind CLI

docs/               состояние по ТЗ, аудит, размещение, разборы
```

Около 13 000 строк своего JavaScript в 48 файлах.

## Как запустить у себя

Node не нужен — на машине его и нет. Всё делают три скрипта PowerShell.

Локальный сервер:

```bash
powershell -ExecutionPolicy Bypass -File .\tools\serve.ps1
```

Проверки (поднимает сервер, если не поднят, и открывает страницу):

```bash
powershell -ExecutionPolicy Bypass -File .\tools\test.ps1
```

Пересборка стилей — нужна после того, как в разметке появился новый
класс Tailwind:

```bash
powershell -ExecutionPolicy Bypass -File .\tools\build-css.ps1
```

Чтобы приложение собирало карточки, нужен бесплатный ключ Gemini из
[Google AI Studio](https://aistudio.google.com/apikey). Он хранится
только в браузере и в репозиторий не попадает. Без ключа работает всё,
кроме добавления слов, чата и рассказов.

Синхронизация необязательна и требует своего проекта Firebase — см.
`docs/DEPLOY.md`.

## Правила, о которых легко забыть

- **Версия правится при каждом изменении.** `VERSION` в
  `js/version.js` — то, что человек видит в «Информации»; `APP_VERSION`
  в `sw.js` — то, что сбрасывает офлайн-кэш. Без второго пользователь
  останется на старом коде и не узнает об этом.
- **Новый файл добавляется в `PRECACHE_URLS`** в `sw.js`, иначе экран
  не откроется без сети. Забыть это легко, заметить — трудно, поэтому
  список сторожит проверка `tests/suites/offline.test.js`.
- **Новый класс Tailwind требует пересборки** `css/tailwind.css`.
  Классы, собираемые из кусков во время работы, в сборку не попадают —
  их место в `safelist` в `tailwind.config.js`.
- **Числа, названные в справке, сверяются с кодом** проверками в
  `tests/suites/guide.test.js`. Меняете шаг заучивания или потолок
  повторений — правьте и текст в `js/i18n/guide.js`.

## Проверки

297 проверок в 19 наборах, прогоняются в браузере одной командой без
Node и без сети. Основание — чистая логика: разбор форм, интервалы,
освоенность, варианты ответа, статьи Wiktionary. Сверху шесть сквозных
сценариев, идущих по отдельной базе: словарь живого человека они не
видят и не трогают.

## Размещение

GitHub Pages, раздача из ветки `main`. Публикация — обычный `git push`;
через минуту сборка проходит сама. Подробности, включая переезд на свой
домен и настройку Firebase, — в `docs/DEPLOY.md`.
