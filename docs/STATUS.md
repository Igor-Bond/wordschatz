## Ближайшие решения

- **Схема карточки.** Род отдельным полем и структурированное спряжение требуют новой версии базы. Старые карточки этих полей не имеют — решается миграцией и дозаполнением.
- **Облако.** Выбран Firebase (бесплатный тариф Spark): Authentication для входа через Google, Firestore для данных.
- **Авторизация.** Делается в начале работы с облаком, до синхронизации.
